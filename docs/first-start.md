# Первый запуск

Это план проверки, а не отчёт о выполненной установке. Подробные команды и распиновку добавим после получения оборудования и проверки актуальной документации.

## Сервер

1. Снять комплектацию, записать модель, CPU, RAM, накопитель и исходную систему.
2. Проверить запуск, сеть и состояние накопителя. Выяснить, есть ли нужные данные на диске, прежде чем устанавливать другую ОС.
3. Для выбранной архитектуры подготовить Proxmox VE и виртуальную машину Home Assistant OS. На старте планируем для HAOS 2 vCPU, RAM 4 ГБ и виртуальный диск 64 ГБ; назначения уточним при установке.
4. Подключить сервер по Ethernet, проверить доступ к Home Assistant после перезагрузки.
5. Сохранить первую резервную копию вне системного SSD. Снимок виртуальной машины на том же диске не заменяет такую копию.

## Датчик

1. Проверить маркировку ESP32-S3, USB-разъёмы и подключение к компьютеру.
2. Подготовить минимальную прошивку ESPHome без датчика и проверить Wi-Fi и подключение к Home Assistant.
3. При отключённом питании подключить модуль SHT31-D: питание, GND, SDA, SCL. Конкретные GPIO и питание выбираем по схеме фактических плат. Логика ESP32 — 3,3 В; подтяжки I²C должны быть совместимы с ней.
4. Получить температуру и относительную влажность в Home Assistant.
5. Проверить отключение питания и восстановление связи; оставить макет на сутки с журналом наблюдений.

## Результат первой вехи

- Home Assistant доступен после перезапуска сервера.
- Датчик передаёт температуру и влажность и восстанавливает подключение после перезапуска.
- Сохранены схема, версии ПО и конфигурация без действующих секретов.
- Резервная копия хранится отдельно.
